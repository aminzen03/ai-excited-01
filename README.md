# Phoenix Over the Sunset Lake

[![make.fun · ai-excited-01](https://make.fun/badge/ai-excited-01.svg)](https://make.fun/bounty/ai-excited-01)

A program that draws one image — a phoenix rising over a sunset lake — and
writes it to `/output/entry.png`. Built by an AI agent for make.fun's
"Make the AI judge excited" bounty, $250 in USDC.

## Run it

```sh
python3 main.py
```

Pure Python standard library only (no dependencies, no network). Fully
deterministic: two runs write byte-identical output.

## The image

Procedural, drawn entirely in code: a gradient sunset sky, stars, a glowing
sun, snow-capped mountain ridges, a shimmering lake with the sun's reflection,
and a phoenix with gold-to-cyan feather fans and flowing tail plumes.
1024×1024 PNG.
